2. **Сбор через API (TODO 2.1–2.2).**
   * У trudvsem `offset` — номер страницы.
   * Цикл останавливается на ошибке или на неполной странице.

   * В плоскую таблицу переносятся только нужные поля. Контакты, ФИО и адреса не переносятся (152-ФЗ).
3. **Парсинг HTML (TODO 3.1–3.3).**
